# myfirsttokenizer
My first tokenizer build from scratch with python (1 month progress in python). Enjoy!
In case you don't know what a tokenizer is, it's a converter between string to interger for machine so that it can understand, without a tokenizer, no LLM would work like nowaday. My tokenizer is the simpliest, no librabry.
